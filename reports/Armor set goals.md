Existing alternate stat versions with the same appearance still count together, as previously approved.

This inventory supersedes the grouped armor-set entries in the earlier Goal banner shot list. For each missing image, find the exact named set on its matching class. PvP art must match the listed faction and Forever appearance. Race is flexible where that class is playable on the photographed client.
