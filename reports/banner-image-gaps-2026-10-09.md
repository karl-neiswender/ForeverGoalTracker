# Banner artwork gap audit

Audited 2026-10-09 against 138 individual goal definitions on the Forever client. Collection-only Library parents excluded. Player used for baseline: Human Warrior, Alliance. No-art results are goal mappings, not a claim that source artwork is unavailable.

## Tier 1-3 dedicated art

| Class | Dedicated tiers still missing | Current fallback |
|---|---|---|
| Paladin | Tier 1 | Shared Molten Core |
| Priest | Tier 1, Tier 2, Tier 3 | Molten Core / none / floating Naxxramas |
| Hunter | Tier 3 | Floating Naxxramas |

Warrior, Rogue, Mage, Druid, Shaman and Warlock have dedicated Tier 1, 2 and 3 banners. Tier 2 Priest is also counted in the no-mapping list below.

## Older artwork awaiting current treatment

- Charger: existing legacy banner, with edited review saved but not installed.
- Naxxramas raid: existing legacy banner; current floating Naxx is installed for Tier 3 and attunement, not the raid.

## Character-aware leveling variants

Available faction/class combinations: Alliance Hunter, Mage, Warrior, Druid, Paladin; Horde Hunter, Warrior, Shaman, Warlock.

- Missing Alliance-specific class variants: Priest, Rogue, Shaman, Warlock.
- Missing Horde-specific class variants: Mage, Priest, Rogue, Druid; Paladin if applicable to supported characters.
- More exact race/class variants can be added whenever approved art exists. Current race-tagged variants are Night Elf Hunter, Human Mage, Dwarf Warrior, Night Elf Warrior and Tauren Shaman. Other races use their compatible faction/class image or shared art.
- No approved Horde Mage is registered; a Troll Mage would be the highest-priority addition for Karl's example.

## Racial mounts

- Missing dedicated race banners: Gnome (mechanostrider), Undead/Scourge (skeletal warhorse), Skyborne (galestrider).
- Installed: Human horse, Dwarf ram, Night Elf nightsaber, Orc wolf, Troll raptor, Tauren kodo.
- Missing race art uses a sole selected same-faction mount, then a same-faction mount; unknown faction has no mount fallback.

## PvP

Faction selection already works with approved Alliance night elf Warrior and Horde orc Warrior images. No functional faction gap, but dedicated PvP compositions per faction remain an optional art improvement. Unknown faction uses the shared PvP scene.
