# Show and hide icon artwork, 2026-10-24

Created four PNG originals using built-in imagegen, matching the existing silver
and gold icon sheets. Each is 1254 x 1254, 32-bit RGBA; corner and interior-gap
samples confirm transparent alpha. Hide slashes run bottom left to top right (/),
matching map-location-off. Visually reviewed all four outputs.

Files in Media/artwork/ui-icons:
- eye-white-generated-original.png: silver show
- eye-off-white-generated-original.png: silver hide
- eye-generated-original.png: gold show
- eye-off-generated-original.png: gold hide

Prompt set: create a single horizontal almond eye with a circular metal iris and
transparent pupil, matching sheet-white-source.webp: thick sculpted silver,
angular chiseled bevels, subtle hammered texture, upper-left highlights, charcoal
recesses, transparent negative spaces, no text or glow. Derive hide by adding
one matching beveled slash from bottom left to top right while preserving the eye.
Recolor each to match sheet-source.webp: yellow-gold highlights, golden faces,
amber recesses and dark brown contour, preserving geometry and transparency.

PNG artwork delivery only. Runtime textures and Lua integration were not changed.
No native game review performed.
