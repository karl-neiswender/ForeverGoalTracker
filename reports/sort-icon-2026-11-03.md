# Sort icon

Gold sort icon available as `FGT.Icon("sort")`.

- Runtime texture: `Media/icons/sort.tga` (64 x 64, RGBA).
- Source copy: `Media/icons/sort-source.png`.
- Untouched generated original: `Media/artwork/ui-icons/sort-generated-original.png`.

Generated with built-in imagegen using the user's two-triangle sort reference
for shape and `Media/icons/sheet-source.webp` for the chiseled gold style. The
prompt requested two equal stacked triangles, the upper pointing up and the
lower pointing down, with a clear gap, faceted bevels, amber recesses, warm
upper-left highlights, a dark brown outline, and transparent background.
No text, frame, tile, or glow.

Converted with `tools/icon.py` and palette matched with `tools/gold.py`.
The 64 px texture was inspected at 4x scale. A full WoW restart is needed when
the icon is first wired into the UI.
