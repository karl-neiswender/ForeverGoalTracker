Karl identified and selected the Cenarion image as a hippogryph. The key art is a thematic selection for the existing Scholomance Skeleton Key goal. Lady Anacondra depicts the dungeon/boss theme rather than the wearable set.

Method: one successful built-in ChatGPT image edit per source, then technical Lanczos export to 1200 x 800 optimized JPEG at quality 90. Requested neutral monochrome, moderately stronger contrast, subject right of center and above midpoint, quieter left text area, original illustration details preserved, no baked vignette. Generative edits can alter painted details; see the comparison for review. Originals were left untouched. Lok'delar completed in the first batch; a connection error interrupted the other four, which succeeded on retry.
